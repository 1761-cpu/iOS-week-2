# Computer Lab App

Hi Ms. Phượng, my name is **Võ Châu Anh**. This is my submission for building the Computer Lab App.

This practice asks to build an iOS app that manages the computers in a lab using SwiftUI, allowing users to view a list of computers, add new ones, check whether a computer exists in the lab, and see statistics of all computers.
