# Class Management System

Hi Ms. Phượng, my name is **Võ Châu Anh**. This is my submission for building the Class Management System app.

This practice asks to build an iOS app that manages a list of students in a class using SwiftUI. Each student has an **ID**, **name**, and **GPA**. The app supports viewing, adding, editing, and removing students, as well as searching by name/ID, filtering and sorting by GPA.
